## Encrypted CSS and JS in saved pages
- Page CSS, JS, inline page scripts and SVG strings are encrypted with AES-GCM (`enc1:`, with a `b64:` fallback) in the save request and decrypted on load, so a web firewall does not block or read them (`codeCrypto.ts`, `useSavePage.ts`, `query.ts`).
- Tests: `savePayload.test.ts`, `loadDecrypt.test.ts`.
