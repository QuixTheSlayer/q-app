## Grid placeholder overlay — iterated to the right visual pattern

**What:** Added a "grid placeholder" visual aid over a CSS grid container, tied to the row/column count controls in `LayoutSection.tsx`. Implementation lives in `Container` in `src/components/EditorUI/Nodes.tsx` (~line 279 `gridOverlay` memo, ~line 330 overlay JSX), gated by `editorConfig.enable_grid_placeholders`.

**Why:** The first attempt — independent dashed boxes for only the leftover/empty slots (`Array.from({ length: emptySlotCount })`), rendered inline after `{children}` — was technically correct (tsc clean, tests passed) but didn't match what the user actually wanted, so it was replaced.

**How:** Switched to an absolutely-positioned overlay `<div>` spanning the full container, drawn as its own `display:grid` using the *same* `gridTemplateColumns`/`gridTemplateRows` as the real node, iterating **every** cell across the full `columns × rows` extent:
- Unfilled cells get a faint tint plus a `row:col` label (e.g. `1:1`).
- Filled cells show only the grid lines, no tint/label, so they don't compete visually with real content.

This got explicit approval: *"This is what I really want. You understand me."*

**Decision:** Established pattern for future "show me the grid" requests: default to the full-overlay-with-labels pattern above, not a partial/leftover-only rendering.
