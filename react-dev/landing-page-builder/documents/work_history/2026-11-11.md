## Editor hard reload shortcut
- Ctrl or Cmd+R in the editor clears caches and service workers, re-downloads the page and its scripts and styles, then reloads (commit 9e854fd33).
- Fixed along the way: the cache buster used `Date.now.toString()`, the listener was added on every render, and it caught Ctrl+Shift+R and typing fields. It now runs from a useEffect, only in the editor, and skips Shift, Alt and text fields.
- The URL stays clean (no `_cb`). The dev server sends `Cache-Control: no-store`.
- Not possible from a page: emptying the browser's HTTP cache. That needs a `Clear-Site-Data` header from the server, and production needs a `no-cache` rule for index.js and style.css on the real server.
