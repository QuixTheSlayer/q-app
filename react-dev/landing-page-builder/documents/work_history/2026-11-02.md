# 2026-11-02

## Simplified editor top bar (uncommitted)
- The top bar went from seven controls on the right to three: Preview, Save and a More menu. Custom Code, Import HTML, Take a tour and Toggle theme moved into the menu (`EditorMoreMenu.tsx`), each still behind its own flag.
- The Synced badge became plain status text beside the page title: All changes saved, Unsaved Changes, Saving changes, Error Syncing or Saved to local. Save is filled only while there are unsaved changes; Preview is a plain outline button. Labels collapse to icons below the `xl` breakpoint.
- `CustomCodeDialog` and `ImportHtmlDialog` take `open`, `onOpenChange` and `hideTrigger` so the menu can control them. The menu is non-modal, because a modal one left the page unclickable after a dialog closed.
- Playwright specs updated for the new text and the menu (`clickMoreMenuItem` helper). Ran top-bar, custom-code, import-html, onboarding-tour and save-and-preview: all passed except Preview opens the read-only route, where the Preview page does not show its Switch to editor button. That page was not touched here and the cause is not investigated.
