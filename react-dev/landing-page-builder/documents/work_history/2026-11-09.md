# 2026-11-09

## Imported code is never saved
- JS, linked files and CSS from pasted HTML stay in the editor and are left out of every save (`stripImportedCode`, marker `importedCode`). Rendering always drops JS, imported scripts and `@import`.
- New read-only Code for review dialog (`CodeReviewDialog.tsx`) with Copy buttons replaces `CustomCodeDialog.tsx`. The warning (amber, with the support email) is in `CodeBlockedNotice.tsx`.
- Fetch is blocked after page data loads on Preview as well (`useBlockFetchAfterLoad.ts`).

## Tailwind classes in imported HTML
- The AI prompt asks for Tailwind classes. `tailwind.ts` translates them: plain utilities into the node style, `tablet:` and `mobile:` into responsive styles, `hover:`, `active:`, `view:` and `animate-*` into animation effects on `root.animation`, and `click:toggle-[#id]`, show, hide and scroll-to into click actions.
- The JSON style object (`styleObject.ts`) was removed. A navigation pattern with three navs and a hamburger toggle is in the prompt.
- Click effects now bubble up to the nearest node that has one (`useScrollToInteractions.ts`).
- Checked in a real browser at three widths on Render and Preview. Tests: `tailwind.test.ts`. Full run: 57 files, 657 tests, tsc clean.

## Unsaved changes guard
- Browser warning when leaving with unsaved changes, a Preview reminder to save, and an immediate save when the preview size changes. Loading a page no longer marks it unsaved.

## Responsive styles on Preview
- Preview and the capture page did not add the tablet and mobile media rules, so the three-nav pattern did not switch there. They do now.
