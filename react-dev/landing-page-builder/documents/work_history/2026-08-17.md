## Fixed PropertyPanel `hintKey` copy-paste bugs

**What:** Fixed a recurring bug pattern in `src/components/PropertyPanelUI` where several controls' `hintKey` props pointed at the wrong entry in `hints/registry.tsx`:
- Typography "Line Height" vs TextPanel "Line Count" (`WebkitLineClamp`) both used `hintKey="lineHeight"` — split into `lineHeight` and a new `lineClamp`.
- IconBlockPanel "Stroke Width" and SeparatorsPanel "Line Width" also used `hintKey="lineHeight"` — moved both to a new `strokeWidth` hint.
- Typography "Align" (text alignment) used `hintKey="alignX"` (meant for layout/flex horizontal alignment elsewhere) — split into new `textAlign`.
- Typography "Text Style" (bold/italic/underline/list) used the generic `hintKey="typographyGroup"` — gave it its own `textStyle` hint.
- Typography "Script" (superscript/subscript) and SizeSection/ContentSizeSection Min/Max Width/Height rows had no dedicated hint (or reused `height`/`width`) — added `script`, `minWidth`, `maxWidth`, `minHeight`, `maxHeight`.

**Why:** A new control row gets cloned from a sibling row, but its `hintKey` prop is left pointing at the sibling's entry, so the `?` tooltip shows the wrong demo/description for that control. Easy to miss visually since the tooltip still renders fine, just with the wrong content.

**How:** Went through `src/components/PropertyPanelUI` control-by-control, cross-checking each `hintKey` against `hints/registry.tsx` to confirm the referenced entry actually describes that control's own CSS property, and added new registry entries (`lineClamp`, `strokeWidth`, `textAlign`, `textStyle`, `script`, `minWidth`, `maxWidth`, `minHeight`, `maxHeight`) to replace the mismatched or generic ones found above.

**Decision:** When adding or reviewing a new PropertyPanel control going forward, verify its `hintKey` matches a registry entry whose Demo/description actually describes that control's own CSS property — don't assume a hintKey shared with a nearby row is correct. The `audit-property-hints` skill (`.claude/skills/audit-property-hints/SKILL.md`) automates this check; run it before large PropertyPanel additions.
