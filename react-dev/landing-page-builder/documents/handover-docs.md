# Yaku’s Handover

## **1\. Project Overview (Per Project)**

* What the project does (short summary)  
* Main features / modules  
* Tech stack used (React version, libs, etc.)  
* Architecture overview (how things are structured)  
* **Main Objective :** Brief on the development environment so that other developers can resume your work.

## **2\. Codebase Structure**

Explain:

* Folder structure (src, components, services, etc.)  
* State management (Redux / Context / others)  
* Routing structure  
* Reusable/common components

👉 Prefer:

* Screen recording (20–30 mins)  
  * Since it is a recording, pls prepare the agenda of walkthrough

## **3\. Key / Critical Modules ⚠️**

List and explain:

* Most complex components  
* Business-critical logic  
* Areas that are hard to understand

For each:

* What it does  
* Things to be careful about

## **4\. Common Bugs & Debugging Guide**

List:

* Frequent issues  
* Known bugs (not fixed yet)  
* How to debug common problems

##  **5\. Server side Integration**

* Request / response structure  
* flow (token, headers, etc.)  
* Error handling approach

##  **6\. Environment Setup**

* Node version  
* Install dependencies  
  * The purpose of library usage


  

## **7\. Build & Deployment**

* Build command  
* Deployment steps  
* Environment configs  
* Rollback steps (VERY IMPORTANT)  
  


## **8\. “Things NOT to Touch”**

List:

* Fragile code areas  
* Temporary fixes / hacks  
* Parts that may break easily

## **9\. Pending Work**

Provide:

* Incomplete features  
* Known issues  
* Tech debt  
* Future Suggestions for your features  
  * Idea for next step  
  * What should be imporved

* Git repositories  
* Deployment tools

* Third-party services (if any)  
* Reference links  
* Debugging tools
